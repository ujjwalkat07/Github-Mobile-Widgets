A compact, mobile-first Expo + React Native (TypeScript) project that provides lightweight home-screen widgets and UI components for interacting with GitHub data. Built for performance and cross-platform compatibility, it leverages Expo SDK 57 and focuses on fast, accessible mobile experiences.

Key points:

- Mobile-first and performance-oriented: optimized for low memory and fast render on phones.
- TypeScript-first codebase for strong typing and maintainability.
- Includes Android home-screen widgets and reusable mobile components.

Getting started

1. Install dependencies (use Expo to resolve SDK-compatible versions):

   ```bash
   npx expo install
   ```

2. Run the development server:

   ```bash
   npx expo start
   ```

Notes

- This project uses Expo; check `package.json` for the exact SDK and follow the matching Expo docs for breaking changes.
- The repository is private (see package.json). If you make the repo public, add a license file.
